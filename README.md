# VOLTURA Marketplace Storefront

Facebook Marketplace-inspired business storefront for VOLTURA.

## Features
- Professional business profile with cover image, address, hours and WhatsApp
- Product feed with search, category filters and sorting
- Individual product detail pages
- "Order on WhatsApp" buttons with pre-filled messages
- Optional basket that generates a multi-item WhatsApp order message
- Simple admin view (edit products via `js/products.js`)
- Fully responsive

## How to Use
1. Open `index.html` in a browser
2. Browse products, filter, search
3. Click "Order on WhatsApp" or add items to basket then send one WhatsApp message
4. Manage products by editing `js/products.js`

## Admin
Visit `/admin/` for a simple product overview.  
Real product management = edit the JavaScript file or connect a proper backend later.

## Going Live
Host the folder on any static host (Netlify, Vercel, GitHub Pages, cPanel).  
No server required for the current version.
